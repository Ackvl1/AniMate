AniMate MemoryManager — Class Architecture

3-tier memory: sliding window + fact store + semantic summary index

① ConversationMemory（短期）

  • • 滑动窗口，当前对话历史
  • • max_turns=20，超出丢弃最旧
  • • 存内存，退出丢失
  • • MemoryCap.inject_before() 注入 ctx.history
  • → 已有，几乎不改

② FactStore（长期事实）

  • • SQLite 持久化键值对
  • • category: user / fact / relation / emotion
  • • memory tool 暴露给 LLM 自行管理
  • • Frozen Snapshot 模式（Hermes 借鉴）
  • → 新建文件

③ SummaryIndex（语义检索）

  • • 超长时 LLM 压缩成摘要
  • • 摘要 embed 进 VectorStore
  • • 复用现有 RAG 引擎（numpy 余弦）
  • • MemoryCap 检索后注入 system_prompt
  • → 新建文件，复用已有 RAG 代码
