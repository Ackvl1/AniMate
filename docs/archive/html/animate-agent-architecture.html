AniMate Agent Framework — Class Architecture

4-Phase Pipeline: BEFORE → REACT → AFTER → REFLECTION

Phase: BEFORE

  • • 收集 system_prompt_parts
  • • 执行预处理 (RAG 检索、记忆注入、情绪更新)
  • • Capability 按注册顺序执行
  • • [Persona, Retrieval, Memory, Emotion]

Phase: REACT

  • • 唯一内置 Capability (ReactCap)
  • • 组装 messages → 调 LLM
  • • Tool Calling 循环 (max rounds)
  • • 轮数 = max(cap.max_rounds_hint)
  • • 安全上限 10 轮防死循环

Phase: REFLECTION

  • • 同 LLM 评估输出质量
  • • 返回 ReflectionSignal
  • • level=1: 重格式化
  • • level=3: 回退 ReAct
  • • level=4: 回退 Before
